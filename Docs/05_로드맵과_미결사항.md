# 로드맵과 미결사항

> 최종 갱신: 2026-11-23. Phase 1~5 번호는 ChatGPT 확정(결정 로그 2장). 그 이후 순서는 제안안. 확정된 규칙은 01_결정로그.md 참고.

## 1. 로드맵

| 단계 | 내용 | 상태 |
|---|---|---|
| Phase 1 | 기본 전투 (Combatant, 카드·적 데이터, CardManager, PlayerController, EnemyController, CombatManager) | **완료** |
| Phase 2 | CardInstance, startingDeck/runDeck 분리, 카드 개별 강화 | **완료** (커밋 `feat: Phase 2`) |
| Phase 3 | 카드 대상 선택 (targetType, 단일/전체/무작위, 키보드 대상 선택) | **완료** (회귀 8종 통과, 커밋 `feat: Phase 3 대상 선택`) |
| Phase 4 | Buff 및 Special (버프·디버프 4종, 플레이어 Buff 카드, 재정렬 카드 효과, 적 행동 5종 포함 여부 확인) | **다음 단계 — ChatGPT 확정 대기** |
| Phase 5 | 전투 UI 프로토타입 (체력·에너지, 손패 클릭, 적 클릭 대상 선택, 턴 종료 버튼, 승패 화면) | 확정 |
| 이후 (제안) | 카드 보상·골드, 수학 공식 시스템 1차, 스킬·유물, 분기형 맵, 상점, 휴식(카드 강화 연결), 이벤트, 보스 기믹, 도감 UI, 영구 저장 | 순서 미정 |

## 2. 미결사항 (ChatGPT 결정 필요)

### Phase 4 전
1. 적 행동 5종(SelfBuff / AllyBuff / AllyHeal)을 Phase 4에 포함할지, 포함한다면 구체 효과와 수치
2. 아군 대상을 "하나" 고르는 기준 (무작위 / 리스트 순서)
3. 플레이어용 Buff 카드가 주는 효과와 수치, 대상(Self만인지, 적에게 거는 디버프 카드도 있는지)
4. 공격력 보정이 적용되는 범위 (카드 피해만 / 적 공격에도 / 전체 공격·무작위 공격의 각 타격마다)
5. 방어도 보정이 적용되는 범위 (방어 카드만 / 적의 방어 행동에도)
6. 버프 지속시간 감소 시점의 세부 (부여된 그 턴도 1로 세는지)
7. 버프 상태를 확인하는 방법 (로그 / 인스펙터) — UI 전까지

### 보상·상점 단계 전
8. 카드 풀 구성과 카드별 등급 지정
9. 골드 획득량, 상점 가격
10. 보상 건너뛰기 여부

### 밸런스
11. 카드 강화 수치의 최종값 (현재 타격 9 등은 검증용 임시값)
12. 임시 카드(Strike, Guard 등)를 대체할 실제 수학 카드 설계

### 수학 시스템 (해당 단계 진입 전)
13. 수학 분류 체계, 공식 표현 방식, 카드의 수학적 효과와 강화의 관계
14. 도감 데이터 구조와 해금 조건
