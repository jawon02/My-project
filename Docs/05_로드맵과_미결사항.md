## 2. 미결사항 (ChatGPT 결정 필요)

2. ~~아군 대상 고르는 기준~~ → 자신 제외, 살아 있는 적 중 가장 왼쪽
3. ~~플레이어 Buff 카드의 효과·수치·대상~~ → 집중·약화·견고·균열
4. ~~공격력 보정 범위~~ / 5. ~~방어도 보정 범위~~ → 효과를 가진 쪽의 공격·방어에 적용

7. ~~버프 상태 확인 방법~~ → 로그 + 인스펙터

### 보상·상점 단계 전
8. 카드 풀 구성과 카드별 등급 지정
9. 골드 획득량, 상점 가격
10. 보상 건너뛰기 여부

### 밸런스

### 수학 시스템 (해당 단계 진입 전)
